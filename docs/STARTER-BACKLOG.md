## Acceptance criteria for contributions
Clear scope, upstream sources, license compatibility assessment, no secrets or customer data, reproducible tests, and PR review.

## Explicit exclusions
No private NIKWAY code import, private repository mirroring, customer data, actual credentials, infrastructure administration or production changes.
