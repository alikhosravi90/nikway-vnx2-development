# فهرست کارهای اولیه توسعه عمومی

این موارد پیشنهاد همکاری‌اند، نه مجوز تغییر محیط عملیاتی.

## پژوهش و مستندسازی
- [ ] مقایسه ابزارهای متن‌باز A3، 5 Why، 5S، SPC، VSM و مدیریت پروژه همراه با بررسی مجوز.
- [ ] مستندسازی روش اتصال Open edX به SSO، xAPI/LRS و مجوز دسترسی به دوره.
- [ ] طراحی شِمای عمومی Tool Manifest شامل شناسه، نسخه، مجوز، قابلیت، دسترسی و پشتیبانی آفلاین.
- [ ] پیشنهاد قرارداد API برای اجرای ابزار و پیوند خروجی آن به مسئله بهبود.
- [ ] طراحی سناریوی مصنوعی Insight → Learning → Tool → Improvement → Evidence.
- [ ] تولید نمونه‌های مستقل غیرعملیاتی با داده ساختگی.
- [ ] تعریف آزمون‌های قابلیت انتقال و اجرای آفلاین.

## معیار پذیرش
دامنه روشن، منبع بالادستی، بررسی سازگاری مجوز، نبود اطلاعات محرمانه، آزمون قابل‌تکرار و بازبینی PR.

## موارد خارج از محدوده
انتقال کد خصوصی، کپی تاریخچه مخزن اصلی، داده واقعی مشتریان، رمزها، مدیریت سرور و تغییر Production.
