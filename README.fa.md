# نیک‌وی vNx2 — همکاری در توسعه

**NIKWAY — راه نیک؛ مسیر بهبود مستمر**

این مخزن عمومی برای همکاری توسعه‌دهندگان، بررسی ابزارهای متن‌باز، ساخت نمونه‌های مستقل و مستندسازی فنی نیک‌وی ایجاد شده است.

> **وضعیت:** طراحی و توسعه مشارکتی اولیه. این مخزن حاوی کد خصوصی پلتفرم اصلی یا تنظیمات محیط عملیاتی نیست.

## چشم‌انداز
کمک به افراد و سازمان‌ها برای تبدیل دانش به قابلیت، قابلیت به اقدام و اقدام به بهبود قابل‌اندازه‌گیری.

## بخش‌های اصلی
- **Platform:** مدیریت دانش، Insight، Improvement، قابلیت‌ها و فرایندهای هوشمند.
- **Academy:** آموزش و کارگاه؛ Open edX به‌عنوان موتور LMS هدف انتخاب شده است.
- **Tools:** جعبه‌ابزار تخصصی Lean، کیفیت، آمار، فرایند و مدیریت پروژه با اولویت بازاستفاده از منابع متن‌باز.
- **Store:** کیت‌ها، ابزارها و محصولات فیزیکی و دیجیتال.
- **Community:** یادگیری جمعی، گروه‌های تخصصی و شبکه متخصصان.
- **Consulting و Marketplace:** خدمات حرفه‌ای و عرضه محصولات و خدمات شرکا.

## جهت‌گیری معماری
- **اول بازاستفاده، بعد توسعه اختصاصی.**
- مرزبندی دامنه‌ای و قراردادهای API نسخه‌دار، بدون ریزسرویس‌سازی زودهنگام.
- استقرار قابل‌انتقال در ابر، نسخه اقتصادی و محیط آفلاین.
- درگاه AI مستقل از ارائه‌دهنده.
- امنیت، جداسازی اطلاعات سازمان‌ها، کنترل دسترسی، ثبت شواهد و بازیابی.
- منابع منطقی مستقل برای Tools، Knowledge، Academy و Store.

## فناوری‌های پیشنهادی
Frappe/ERPNext، Open edX، Temporal، Keycloak، React/Next.js، Python، OpenTelemetry و ابزارهای متن‌باز سازگار. انتخاب نهایی هر وابستگی به بررسی مجوز، امنیت و سازگاری نیاز دارد.

## امنیت و محرمانگی
اطلاعات ورود، کلیدهای API، داده مشتریان، مشخصات زیرساخت خصوصی، کد محرمانه و تاریخچه مخزن خصوصی را منتشر نکنید. فقط از داده مصنوعی استفاده کنید. آسیب‌پذیری‌ها را به‌صورت خصوصی گزارش کنید.

## مجوز
انتشار عمومی به معنی اعطای مجوز عمومی برای برند NIKWAY یا دارایی‌های خصوصی آن نیست. مجوز مشارکت‌های جدید باید پیش از پذیرش کد مشخص شود.
