# Contributing to NIKWAY vNx2

We welcome design discussions, source-backed OSS comparisons, isolated prototypes, API contract proposals and tests.

1. Open an issue describing the user problem, expected behavior, alternatives and acceptance criteria.
2. Prefer existing maintained open-source components over rebuilding them.
3. Include upstream repository URL, exact license, maintenance/security observations and integration cost.
4. Use only synthetic data and public documentation. Never copy private NIKWAY files, secrets, tenant data or deployment configuration.
5. Submit changes through feature branches and pull requests. Include reproducible tests and an explicit rollback strategy where relevant.
6. Do not claim a feature is deployed or production-ready without evidence.
7. Avoid new dependencies unless necessary; note supply-chain and license implications.
8. Never attempt access to internal infrastructure or privileged connectors.

**Current repository state:** design and contribution scaffolding only. Source code and production infrastructure are not included.
