# Security Policy | سیاست امنیتی

## Scope
This is a **public collaboration scaffold**, not NIKWAY's private production repository. Do not submit credentials, personal data, customer data, internal network details or proprietary files.

## Reporting vulnerabilities
**Do not create a public issue for a vulnerability.** Use GitHub's **Report a vulnerability** option under the repository's Security tab if private vulnerability reporting is enabled. If unavailable, contact the repository owner through a verified private channel before sharing technical details. Do not include secrets in reports.

Include an impact summary, affected public files/version, minimal reproduction using synthetic data, and suggested remediation. Do not probe private NIKWAY systems or customer environments.

## Supported versions
No production or security-supported release exists yet. All content is pre-release documentation/scaffolding.

## Maintainer process
Acknowledge privately when possible, triage severity, reproduce safely, fix in a restricted workflow, and coordinate disclosure only after mitigation.

## فارسی
این مخزن عمومی است و نسخه عملیاتی محصول نیست. آسیب‌پذیری را در Issue عمومی گزارش نکنید. از گزینه خصوصی **Report a vulnerability** در بخش Security (در صورت فعال بودن) یا مسیر ارتباط خصوصی تأییدشده با مالک مخزن استفاده کنید. اطلاعات محرمانه و داده مشتری را منتشر نکنید.
